// PROJECT — INTELLIGENT PHYSICAL SECURITY ANALYTICS PLATFORM
What it does

Ingests real-time event streams from physical security infrastructure — access control (ACAM), CCTV (VSS), intrusion detectors, and ISMS — and applies ML anomaly detection to surface threats rule-based systems miss. Unusual access sequences, off-hours events, and correlated multi-zone alerts are scored and surfaced to operators in real time.

How it works

Events flow through Kafka into Spark Structured Streaming. An LSTM Autoencoder trained on normal access sequences learns expected behaviour per zone. Reconstruction error is the anomaly signal — no labelled attack data required. Five architectures (Standard, Sparse, VAE, LSTM, 1D-CNN) benchmarked in MLflow. Best model served via FastAPI with live threshold tuning and a Streamlit monitoring dashboard.

Why it matters

Physical security systems generate thousands of events per day. Operators miss correlated threats buried in noise. This adds an intelligence layer on top of existing hardware without replacing it. The LSTM-AE achieves 0.94 AUROC with 0.923 recall — keeping false negatives low in a security context where missing a real threat is costlier than a false alarm.
